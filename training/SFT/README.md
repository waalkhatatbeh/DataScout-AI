# SFT Training

This folder contains the Supervised Fine-Tuning (SFT) training implementation for DatasetScout AI.

## Files
- `train_sft.py`: Main SFT training script.
- `run_sft_kaggle.py`: Kaggle training launcher.
- `config.yaml`: SFT training configuration.
- `preflight_audit.json`: Dataset preflight audit.
- `SFT_Training_Results.md`: Training and validation results.

The SFT model was initialized from the CPT checkpoint.

Model checkpoints and training datasets are stored separately and are not included in this repository.
